## 🔬 Featured Research

**Reward-Guided Fine-Tuning of Whisper for Low-Resource Code-Switched ASR**  
*CHiPSAL 2026 (Oral Presentation) · LREC-COLING · Mallorca, Spain*

> Designed a reward-guided training framework for OpenAI Whisper using a Random Forest reward model to intelligently filter noisy samples from a 70+ hour Nepali-English code-switched dataset.  
> Achieved an **11–12% relative reduction in WER** – a state-of-the-art result for low-resource Nepali ASR.
